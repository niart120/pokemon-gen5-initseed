# Miscタブ レポ針検索 UI仕様

## 目的
レポートの針（0–7 の離散方向）を観測したデータを入力し、以下を行う:
- Boot-Timing と Timer0/VCount を特定しつつ、観測に対応する現在の消費位置を求める。
- 既知の LCG Seed から現在の消費位置を求め、針列の完全一致で検証する。

## 用語と前提
- レポ針: 1消費につき得られる0–7の方向値。既存実装の `needle`/`dir` に対応。
- 針列: 0–7の数字のみで構成された連続文字列（例: "0425"）。単一入力欄で扱う。
- 消費位置: 対象シード系列における針列の最終要素が一致した位置（例: 針列 "4235" が連続一致した場合は末尾の "5" に対応する消費位置を表示）。
- 一致条件: 針列は完全一致のみ。部分一致や誤差許容は行わない。

## 配置とレイアウト
- Miscタブ下部3カラムの空きスロットに「レポ針検索」カードを追加する。
- カード内でモード切替（セグメントトグル）を行い、内容セクションのみを差し替える。ラベルは LCG Seed / Boot-Timing。
- カード上部に共通操作バー（開始/一時停止/再開/停止、リセット、コピー）が並ぶ。

## 共通UI要素
- アクティブプロファイル: 現在選択中のプロファイルを参照し、Timer0/VCountの初期範囲を自動補完する（編集可）。
- 針入力:
  - 針列入力欄（テキスト、0–7 のみ、長さ1–128）。
  - 入力補助ボタン: 0〜7のボタンを並べ、クリックで末尾に追記。連打で連続追記可能。
- 実行操作: Start / Pause / Resume / Stop。状態は idle/running/paused/completed/error を文言で表示（進捗バー・件数表示は行わない）。
- バリデーション: 未入力、0–7以外、長さ上限超過を即時エラー表示。針列が1文字以上必須。

## モード別仕様
### LCG Seed（消費位置特定）
- 目的: 既知の LCG Seed から観測針列が一致する消費位置を求める。
- 入力項目:
  - LCG Seed: 16進の LCG Seed（上位/下位を含む任意長の16進、必須）。
  - Timer0/VCount: プロファイルから自動補完、編集可。
  - 消費探索: 開始/終了インデックス（例: 0–2000）。上限 0–100000 を超えた場合はエラーで即時拒否。
  - 針列（共通部品）。
- 出力: 消費位置 / Timer0 / VCount を行単位で表示。Seedは行ヘッダやツールチップで補足（列には含めない）。

### Boot-Timing
- 目的: 観測針列から起動時刻・Timer0・VCount候補を特定し、対応する消費位置を求める。
- 入力項目:
  - 起動日時: 日付入力 + 時刻入力（秒まで）。ローカルタイムをISO化して保存。必須。
  - キー入力: 12ビット相当のキー入力マスクをダイアログで選択（既定は全解除）。`KeyInputDialog` を用い、選択結果を「実際に押下するキー集合」として単一マスク保存・表示はキー名列挙（組合せ展開はしない）。
  - Timer0/VCount: プロファイルから自動補完、編集可。
  - 針列（共通部品）。
  - 消費探索: 開始/終了インデックス（例: 0–2000）。
- 出力: 消費位置 / Timer0 / VCount を行単位で表示。起動時刻が推定できる場合は行の補足情報として表示（列には含めない）。

## 結果テーブル
- 列構成: 消費位置 / Timer0 / VCount / 初期Seed / 現在Seed。
- 並び: 消費位置昇順の固定表示。ソートやフィルタUIは設けない。
- コピー: 表示行を TSV/CSV 形式でクリップボードコピー。

## エラー・完了時の挙動
- 完全一致が0件の場合は「一致なし」を明示表示。
- 実行中は針入力と範囲入力をロックし、Pause/Stopのみ有効。
- Stop/Resetで結果とステータスをクリアし、針列など入力値は初期値へ戻る（Timer0/VCountはプロファイル反映値を保持）。

## 実装メモ（開発者向け）
- 針値の扱いは既存の `needle`/`dir`（0–7）と同一の型・アイコンを再利用する。
- 針列の消費位置判定は、連結した針列の完全一致を前提に「末尾が一致した消費インデックス」を返す。
- 計算は必ず Worker 経由で行う。UIは開始/停止と結果表示に専念し、ブラウザ側に進捗バーは持たない。
- 起動時刻はISO文字列として保持し、キー入力はビットマスクで保持・バリデーションする。
- バリデーション（針列長・範囲上限・日時必須など）は UI 層の仕様と同期させ、UI/Worker で同一文言を用いる。
